# AquaLens — Demo Video Script (target 3:30)

Record at 1080p, browser at desktop width (split view shows best). Keep the cursor
calm. Total: ~3.5 minutes.

## 0:00–0:20 — Hook (show the app home screen)
> "Urban streams are watched by citizens — but citizen data is noisy, and today's
> tools only catch the errors weeks later. I built AquaLens: a field companion that
> interviews you like an ecologist and cross-checks your answers *while you're still
> standing at the water.*"

## 0:20–1:30 — The interview (click "Start a stream check")
- Type a stream name. Answer briskly: *Slightly cloudy → Earthy → Floating litter →
  Dragonflies → No rain → Not sure about the outlet.*
- Narrate: "Seven plain-language questions. No jargon — my grandmother could do this.
  Watch the field report building live on the right."
- (Don't linger; this is setup, not the star.)

## 1:30–2:10 — THE moment: contradiction (do a second check, or pre-answer to trigger)
- Answer: *Crystal clear → Rotten egg smell.*
- Pause. Let the flag card appear on screen. Read it aloud:
  > "Something doesn't add up — 'A rotten-egg smell comes from hydrogen sulfide,
  > released as organic matter decays. That same decay clouds water.'"
- Click **"Let me recheck"**, change clarity to *Slightly cloudy*.
- Say: "The AI argued with me — politely, with reasons — and I had the final say.
  That is the whole product."

## 2:10–3:00 — The snapshot (scroll the field report)
- Score ring + grade: "72, Fair — but look *why*: every deduction lists its points
  and its reason. Murky after heavy rain? The app halves the penalty and tells you."
- Confidence meter: "88% — it drops when I override a flag, because honesty."
- One Health card: read one aloud — "Too many nutrients → algal blooms → oxygen
  crash → keep kids and pets out of the mats."
- Cross-checks list: "Every flag and my resolution, logged as data-quality metadata
  researchers can actually use."

## 3:00–3:30 — Honest close (back to home screen)
> "Lens isn't pretending to be machine learning — it's an explainable companion, and
> it says so inside the app. No backend, no API keys, no install: this runs anywhere,
> which is the point — citizen science has to meet people at the water's edge.
> AquaLens: your stream has a story. Lens helps you read it."

## Recording tips
- Do the contradiction check as a **second** run so the first clean run shows the
  happy path; or script answers to hit R1 in one run (clear + rotten).
- If a click misfires, keep recording — do a second take, don't edit mid-flow.
- End card: prototype URL + GitHub repo link, 3 seconds.
